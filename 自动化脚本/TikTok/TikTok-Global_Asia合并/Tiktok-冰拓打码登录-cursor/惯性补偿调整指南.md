# 惯性补偿调整指南

## 问题现象
✅ 滑块可以移动了！
⚠️ 但是会超出目标位置一段距离

## 原因分析

**惯性效果**：
- `gesture()` 函数模拟手指拖拽，会有惯性滑动
- 即使路径终点是目标位置，滑块也会因为惯性继续滑动一小段距离
- 就像真实的物理滑动一样

## 已添加的解决方案

### 自动惯性补偿

代码已添加动态补偿逻辑：
```javascript
// 根据滑块宽度动态计算补偿值
var inertiaCompensation = Math.min(20, Math.max(10, sliderWidth * 0.15));
adjustedTargetX = adjustedTargetX - inertiaCompensation;
```

**补偿规则**：
- 基础补偿：滑块宽度的 **15%**
- 最小补偿：**10像素**
- 最大补偿：**20像素**

**示例**：
- 如果滑块宽度 = 100像素 → 补偿 15像素
- 如果滑块宽度 = 50像素 → 补偿 10像素（最小值）
- 如果滑块宽度 = 200像素 → 补偿 20像素（最大值）

## 如何微调

### 情况1：还是滑过头（补偿不够）

**现象**：滑块还是超出目标位置

**解决**：增加补偿值

找到代码第1907行：
```javascript
var inertiaCompensation = Math.min(20, Math.max(10, sliderWidth * 0.15));
```

修改为（增加补偿比例和最大值）：
```javascript
// 方案A：增加补偿比例到20%
var inertiaCompensation = Math.min(30, Math.max(15, sliderWidth * 0.20));

// 方案B：固定补偿值（如果滑块大小固定）
var inertiaCompensation = 25; // 固定补偿25像素

// 方案C：更激进的补偿
var inertiaCompensation = Math.min(40, Math.max(20, sliderWidth * 0.25));
```

### 情况2：滑不到位（补偿过度）

**现象**：滑块没有到达目标位置，差一点点

**解决**：减少补偿值

修改为（减少补偿）：
```javascript
// 方案A：减少补偿比例到10%
var inertiaCompensation = Math.min(15, Math.max(5, sliderWidth * 0.10));

// 方案B：更小的补偿
var inertiaCompensation = Math.min(10, Math.max(3, sliderWidth * 0.05));

// 方案C：不补偿（测试用）
var inertiaCompensation = 0;
```

### 情况3：每次偏差不一样

**现象**：有时多有时少，不稳定

**可能原因**：
1. 拖拽速度影响惯性
2. 系统性能影响

**解决方案**：
1. 调整拖拽速度（减慢）
2. 增加路径点数（更平滑）

找到代码第2305-2306行：
```javascript
// 增加步数，让拖拽更平滑

// 增加拖拽时长，让滑动更慢

```

## 精确调整方法

### 方法1：测试并记录

1. 运行脚本，查看日志中的实际偏差
2. 如果滑过头 X 像素，就把补偿值增加 X
3. 重复测试直到精确

**示例**：
```
测试1: 补偿15px，结果超出10px → 调整为25px
测试2: 补偿25px，结果差5px → 调整为20px  
测试3: 补偿20px，完美对齐 ✓
```

### 方法2：根据滑块宽度分段

如果发现不同宽度的滑块需要不同补偿：
```javascript
var inertiaCompensation;
if (sliderWidth < 60) {
    inertiaCompensation = 8;  // 小滑块
} else if (sliderWidth < 100) {
    inertiaCompensation = 15; // 中等滑块
} else {
    inertiaCompensation = 25; // 大滑块
}
```

### 方法3：根据移动距离调整

距离越远，惯性越大：
```javascript
var distance = Math.abs(adjustedTargetX - startX);
var inertiaCompensation = Math.min(30, distance * 0.05); // 距离的5%
```

## 其他可能的优化

### 优化1：减慢拖拽速度

惯性与速度成正比，减慢可以减少惯性：

找到 `performDrag` 函数（约2297行）：
```javascript
// 修改前
var dragDuration = Math.max(1500, Math.min(4000, baseDuration));

// 修改后（更慢）
var dragDuration = Math.max(3000, Math.min(6000, baseDuration));
```

### 优化2：改变缓动函数

`easeInOutCubic` 在结尾会减速，可以尝试其他缓动：

```javascript
// 线性缓动（无加减速）
function linear(t) {
    return t;
}

// 只有开始加速，结尾匀速
function easeIn(t) {
    return t * t;
}
```

### 优化3：手动微调最后位置

如果自动补偿不准确，可以在拖拽完成后手动微调：
```javascript
// 在拖拽完成后添加
taskLog("执行微调...");
var adjustDistance = -5; // 向左微调5像素（正数向右）
swipe(adjustedTargetX, startY, adjustedTargetX + adjustDistance, startY, 200);
```
