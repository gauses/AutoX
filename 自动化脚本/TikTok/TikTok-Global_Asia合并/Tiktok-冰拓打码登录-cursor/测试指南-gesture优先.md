尝试3种元素拖拽方式：

**增加路径点数**：
- 之前：15-30个点
- 现在：30-50个点

**更平滑的轨迹**：
- 使用 easeInOutCubic 缓动函数
- 添加微小随机抖动（±1px）
- 强制最后一点精确到达目标

**更慢的速度**：
- 拖拽时长：2-4秒（之前1.5-4秒）
- 更接近人类操作

## 故障排查

### 问题1：gesture执行了但滑块不动

**可能原因**：
1. 滑块验证码不是通过屏幕拖拽的
2. 需要特定的触摸事件序列
3. 验证码有防护机制

**解决方法**：
查看日志中的"滑块元素详细信息"，发给我。

### 问题2：元素方法都不支持

**日志显示**：
```
滑块元素不支持drag方法
滑块元素不支持gesture方法
```

**说明**：这个滑块元素没有拖拽方法。

**下一步**：
- 使用屏幕坐标gesture拖拽
- 或者尝试找到父元素进行拖拽

### 问题3：坐标计算有问题

**日志显示**：
```
警告：移动距离太小（5像素）
```

**可能原因**：
- FrameLayout找错了
- 冰拓返回的坐标有问题
- 滑块已经在正确位置
