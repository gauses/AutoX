
1、安装指定autojs APK:
adb shell settings put global verifier_verify_adb_installs 0
adb shell settings put global package_verifier_enable 0


adb install -g D:\AndroidProject\ApkTool\autojs.apk
adb shell am force-stop org.autojs.autoxjs


2、把js文件复制到手机对应文件夹下面：(FB_gerenfawen就是需要执行的任务对应的文件名字)
adb push FB_gerenfawen.js /sdcard/Download

adb push TikToK_yanghao_liulan.js /sdcard/Download


adb shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE -d file:/sdcard/Download/


3、配置权限：
adb shell settings put secure enabled_accessibility_services org.autojs.autoxjs/com.stardust.autojs.core.accessibility.AccessibilityService

adb shell settings put secure accessibility_enabled 1

adb shell appops set --uid org.autojs.autoxjs MANAGE_EXTERNAL_STORAGE allow
adb shell pm grant org.autojs.autoxjs android.permission.READ_EXTERNAL_STORAGE

adb shell pm grant org.autojs.autoxjs android.permission.SYSTEM_ALERT_WINDOW

//截图权限
adb shell appops set org.autojs.autoxjs PROJECT_MEDIA allow
//如果不能给截图权限， 尝试：shell("screencap /sdcard/screen.png");

4、开始启动，并传递参数：(FB_gerenfawen就是需要执行的任务对应的文件名字)
adb shell am force-stop org.autojs.autoxjs
adb shell am force-stop com.facebook.katana
adb shell am force-stop com.zhiliaoapp.musically
adb shell am start -W -n org.autojs.autoxjs/org.autojs.autojs.ui.main.MainActivity --es "net_script_name" "FB_gerenfawen"


adb shell am start -W -n org.autojs.autoxjs/org.autojs.autojs.ui.main.MainActivity --es "net_script_name" "TikToK_yanghao_liulan"

传JSON：
adb shell am start -W -n org.autojs.autoxjs/org.autojs.autojs.ui.main.MainActivity --es "net_script_name" "{\"rpa_uuid\":\"任务id\",\"account_uuid\":\"82c4541d-ac70-495d-b2e3-d288fb41d360\",\"account_id\":0,\"automation_id\":\"脚本ID\",\"automation_name\":\"TikToK_yanghao_liulan\",\"success\":\"success\",\"rpa_type\":\"NEST_RPA_CM_SCRIPTS\",\"variables\":\"\",\"msg\":\"NEST_RPA_CM_SCRIPTS\",\"Token\":\"Token\"}"


adb shell am force-stop com.kiwibrowser.browser
adb shell pm clear com.kiwibrowser.browser
